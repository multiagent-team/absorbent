# Сравнение бэкендов распознавания речи

Замеры на этой машине (AMD Ryzen 9 5950X; RTX 3060 12 ГБ и RTX 3090 24 ГБ)
на валидационном наборе и на реальной лекции. Короткий вывод: для конвейера
«лекция → конспект» **Whisper turbo точнее и примерно на порядок быстрее**,
а локальный Voxtral Realtime себя не оправдал: поддержка в master не вошла,
реализация, на которой сняты эти цифры, лежит в ветке `voxtral-realtime`.

## Методика

Набор: `google/fleurs`, конфигурация `ru_ru`, сплит `dev` — 356 реплик,
3884 с (64.7 мин) русской речи с эталонными расшифровками (публичный датасет,
тот же, на котором Mistral отчитывается о качестве Realtime-модели).

Метрики: WER и CER через `jiwer` (`process_words` / `process_characters`),
агрегированно по всему набору. Нормализация одинаковая для обоих бэкендов:
нижний регистр, `ё` → `е`, пунктуация заменяется пробелом, пробелы
схлопываются. Числительные цифрами и словами считаются разными словами
(обе модели иногда пишут «за 4 года» вместо «за четыре года»), поэтому
абсолютные значения слегка завышены у обеих.

Запуск: Whisper — `openai-whisper`, модель `turbo`, `language="ru"`,
`beam_size=5` (ровно как в Absorbent с `--language ru`); Voxtral Realtime —
сервер vLLM с настройками из карточки модели и клиент протокола
`/v1/realtime` из ветки `voxtral-realtime` (модуль `realtime.py`), по одной
реплике на сессию. Гонял это одноразовый скрипт: пройти по репликам каталога,
вызвать бэкенд, посчитать `jiwer.process_words` / `process_characters` по
нормализованным строкам; в репозиторий он не добавлен, вся его логика
описана выше.

```bash
# Whisper на 3090
CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=1 \
  uv run --project ~/devel/absorbent --with jiwer \
  python stt_bench.py whisper /tmp/fleurs-bench 0 whisper-3090

# Voxtral Realtime: сервер поднимается отдельно, клиент идёт через absorbent
vllm serve mistralai/Voxtral-Mini-4B-Realtime-2602 --compilation_config '{"cudagraph_mode": "PIECEWISE"}' …
uv run --project ~/devel/absorbent --with jiwer \
  python stt_bench.py voxtral /tmp/fleurs-bench 0 voxtral
```

Осторожно с номерами GPU: без `CUDA_DEVICE_ORDER=PCI_BUS_ID` CUDA нумерует
устройства по скорости, а не по PCI-шине, и `CUDA_VISIBLE_DEVICES=0` на этой
машине означает RTX 3090, а не 3060 (именно так был сорван первый прогон:
Whisper получил занятую двадцатью гигабайтами карту и упал с OOM).

## Качество

| Бэкенд / GPU                | WER        | CER        | S / D / I     | Верных слов  |
|-----------------------------|------------|------------|---------------|--------------|
| Whisper turbo / RTX 3090    | **4.32 %** | **1.65 %** | 222 / 41 / 18 | 6238 из 6501 |
| Whisper turbo / RTX 3060    | 4.34 %     | 1.67 %     | 224 / 41 / 17 | 6236 из 6501 |
| Voxtral Realtime / RTX 3090 | 5.06 %     | 1.98 %     | 245 / 58 / 26 | 6198 из 6501 |

Разбивка по репликам (Whisper на 3090 против Voxtral Realtime):

- лучше Whisper — 65 реплик, лучше Voxtral — 53, одинаково — 238;
- средний WER по репликам: 4.15 % против 5.09 %;
- реплик с WER > 20 %: только у Voxtral — 11, только у Whisper — 3, у обоих — 7;
- пустой ответ: у Voxtral — 1 реплика из 356, у Whisper — ни одной.

Для справки: карточка модели заявляет для этой модели WER 6.02 % на FLEURS
(русский) при задержке 480 мс; наш замер 5.06 % не противоречит — мы подаём
реплику целиком, без паузы в реальном времени.

## Скорость

| Бэкенд / GPU                | Всё аудио (64.7 мин) | RTF   | Быстрее реального времени | Ø на реплику (10.9 с) | Час аудио               |
|-----------------------------|----------------------|-------|---------------------------|-----------------------|-------------------------|
| Whisper turbo / RTX 3090    | 150.7 с              | 0.039 | 25.6×                     | 0.42 с                | ≈ 2.3 мин               |
| Whisper turbo / RTX 3060    | 262.8 с              | 0.068 | 14.8×                     | 0.74 с                | ≈ 4.4 мин               |
| Voxtral Realtime / RTX 3090 | 1420.6 с             | 0.366 | 2.7×                      | 3.99 с                | ≈ 22 мин + ~1 мин старт |

RTF — отношение времени работы к длительности аудио, меньше — быстрее.
Voxtral Realtime медленнее Whisper turbo **в 9.4 раза на той же карте** (и в
5.4 раза, если Whisper поставить на 3060). Причина не в размере весов:
модель потоковая, она выдаёт один текстовый токен на каждые 80 мс аудио, а
движок на одном потоке даёт около 30 токенов в секунду — то есть потолок
≈ 2.4× реального времени. Побочное следствие: неречевые участки (музыка,
тишина) всё равно прогоняются целиком — 300 с музыки стоили тех же ~72 с
GPU при пустом результате.

Старт сервера (~65 с с `cudagraphs`) платится один раз на запуск: в пакетном
режиме — на весь список файлов. Полный прогон конвейера из ветки по каталогу
из двух записей (30 с и 200 с) занял 128 с: старт сервера, два транскрипта,
остановка. На прогоне 10-минутной записи измеримое время — около 2.5 минут
против 16 секунд у Whisper.

## Чем бэкенды ошибаются

На вычитанном тексте (FLEURS) расхождения однотипны — имена собственные,
числительные, морфология:

- «это пятый cep мартейи за четыре года»: Whisper — «сер мартеи за 4 года»,
  Voxtral — «серп мартеи за 4 года» (оба промахнулись мимо имени);

- «дверной звонок работающий от wifi»: оба написали «wi fi» / «Wi-Fi»;
- «определенные потребности и или желания которые накапливаются»: Voxtral
  переводит во множественное/единственное («определенная потребность или
  желание которое накапливается»), Whisper держит число и род;

- реплика «восточно африканские острова находятся в индийском океане…»:
  Voxtral вернул пустую строку (единственный полный провал на наборе).

Сильнее расхождение проявляется на записи лекции, где есть музыкальные
вставки (10-минутный фрагмент реального видео, первые ~203 с — речь, дальше
музыка):

- **Whisper галлюцинирует на музыке**: 14 сегментов «ДИНАМИЧНАЯ МУЗЫКА»
  подряд, последний даже выходит за конец файла (576–606 с при длительности
  600 с). В конспект такой текст попадает как содержание лекции.

- **Voxtral молчит на музыке** — это правильное поведение: пустой фрагмент
  просто не даёт сегмента.

- Зато на смазанной команде лектора Voxtral выдал посторонние слоги
  («надо левый хб остановились надо правый на б остановились»), где Whisper
  написал «Надо левые ноги остановились. Надо правые ноги остановились.».

- Voxtral возвращает текст фрагментами нарезки, а не фразами: пятнадцать
  реплик сливаются в один сегмент без заглавных букв и вопросительных
  знаков. Таймкодов и спикеров у Realtime-модели нет вовсе, `speaker` всегда
  `null`, а границы сегментов — это резы по паузам (`chunk_seconds`).

## Вывод

По совокупности замеров Whisper turbo выигрывает у локального Voxtral
Realtime и по точности (WER 4.32 % против 5.06 %, CER 1.65 % против 1.98 %),
и по скорости (в 9.4 раза), и по структуре результата (таймкоды, короткие
сегменты). Обратная сторона — галлюцинации Whisper на музыке и тишине,
которые попадают в конспект.

Поэтому:

- модель по умолчанию остаётся `whisper-turbo`; для ночной пакетной
  обработки лекций менять её смысла нет;

- локальный Voxtral Realtime из master убран — он оказался в 9.4 раза
  медленнее и менее точным при том же GPU. Его единственная сильная сторона
  (молчание на музыке вместо галлюцинаций) не перевешивает: для потоковой
  расшифровки с малой задержкой он остаётся в ветке `voxtral-realtime`;

- облачный `voxtral-transcribe-2` остаётся единственным вариантом с
  диаризацией спикеров и не затрагивается этими замерами.

Ограничения замеров: один датасет и один язык (русский), чтение вслух;
абсолютные WER зависят от нормализации (числительные, пунктуация).
